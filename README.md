# Sales Data Analysis

## Project Overview

This project focuses on analyzing sales data using MySQL and Excel. The analysis helps understand sales performance, order volume, quantity sold, and other key business metrics.

## Tools Used

- MySQL
- Microsoft Excel

## Key Metrics

- Total Orders: 500
- Total Quantity: 2,259
- Total Sales: ₹30,649,600
- Average Sales: ₹61,299.20

## SQL Analysis

MySQL was used to:

- Create the sales analysis database and tables
- Store and manage sales data
- Perform data analysis using SQL queries
- Calculate sales and order-related metrics
- Analyze product and customer information

## Excel Analysis

Excel was used for:

- Data analysis and calculations
- Filtering and sorting sales data
- Creating summary reports
- Using formulas for analysis
- Understanding sales performance

## Project Files

- `sales_analysis.sql` – SQL database and analysis queries
- `Sales_Analysis.xlsx` – Excel-based sales analysis

## Conclusion

This project helped me practice SQL and Excel for analyzing sales data and generating meaningful business insights.
